#  Core Java Programming Practice

A structured collection of **Core Java programming practice**, covering fundamental concepts, logic building, problem solving, and Object-Oriented Programming.

This repository documents my journey of learning Java from **absolute fundamentals to interview-oriented programming**, with a strong focus on writing clean code and developing problem-solving skills.

---

##  Objectives

* Build strong Core Java fundamentals
* Improve programming logic and problem-solving skills

##  Problem-Solving Approach

For important problems, I focus on understanding the problem before writing the code.

```text
Problem
   ↓
Understand the Requirement
   ↓
Identify Input & Output
   ↓
Think About the Logic
   ↓
Write Pseudocode
   ↓
Implement in Java
   ↓
Test With Examples
   ↓
Check Edge Cases
   ↓
Analyze Time & Space Complexity
```

The goal is not just to memorize code, but to understand **why the solution works**.
